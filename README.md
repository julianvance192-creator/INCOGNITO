# INCOGNITO

Android app that shows a fake location of your choice to any app that tracks you.

## Get the app
1. Put all these files in a new GitHub repository (keep the .github folder).
2. Open the repo's **Actions** tab, pick "Build INCOGNITO APK", press **Run workflow**.
3. When it turns green, open the run and download **INCOGNITO-apk** (a zip with app-debug.apk).
4. Send the APK to your phone and install it (allow "install unknown apps" when asked).

## First use
1. Open INCOGNITO and allow permissions.
2. Developer options > Select mock location app > INCOGNITO.
3. Tap the map, press START.
